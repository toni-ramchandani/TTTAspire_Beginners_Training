# Sources and Verification Boundary

The application corpus is synthetic and versioned. It summarizes the following authoritative public material, verified on 2026-08-18:

## Medical and governance sources

- MedlinePlus, Recognizing medical emergencies: https://medlineplus.gov/ency/article/001927.htm
- MedlinePlus, When to use the emergency room - adult: https://medlineplus.gov/ency/patientinstructions/000593.htm
- CDC, Antibiotic Do's and Don'ts: https://www.cdc.gov/antibiotic-use/about/index.html
- CDC, Manage Common Cold: https://www.cdc.gov/common-cold/treatment/index.html
- CDC, Antibiotic Use and Antimicrobial Resistance Facts: https://www.cdc.gov/antibiotic-use/data-research/facts-stats/index.html
- FDA, The Over-the-Counter Drug Facts Label: https://www.fda.gov/drugs/understanding-over-counter-medicines/over-counter-drug-facts-label
- FDA, Pharmacists Help You Use Medicines Safely: https://www.fda.gov/consumers/consumer-updates/fda-pharmacists-help-you-use-medicines-safely
- FDA, Drug Disposal and Flush List: https://www.fda.gov/drugs/disposal-unused-medicines-what-you-should-know/drug-disposal-fdas-flush-list-certain-medicines
- WHO, Safe and ethical AI for health: https://www.who.int/news/item/16-05-2023-who-calls-for-safe-and-ethical-ai-for-health
- WHO, Guidance for large multi-modal models in health: https://www.who.int/news/item/18-01-2024-who-releases-ai-ethics-and-governance-guidance-for-large-multi-modal-models

## Evaluation framework sources

- Ragas metrics: https://docs.ragas.io/en/stable/concepts/metrics/available_metrics/
- DeepEval metrics: https://deepeval.com/docs/metrics-introduction
- DeepEval G-Eval: https://deepeval.com/docs/metrics-llm-evals
- LangSmith evaluation concepts: https://docs.langchain.com/langsmith/evaluation-concepts
- LangSmith evaluation types: https://docs.langchain.com/langsmith/evaluation-types

The fixed classroom corpus, not the live web, is the source of truth during experiments. Web sources justify and document the corpus but are not retrieved at runtime.
